# House_Price_Prediction

## Project Overview

This project predicts house prices based on various house features using a Machine Learning model. A user-friendly web application was developed using Streamlit, allowing users to enter house details and receive an estimated house price.

## Objective

The objective of this project is to build a predictive model that helps estimate house prices based on factors such as:

* Number of Bedrooms
* Number of Bathrooms
* Living Area
* House Condition
* Number of Schools Nearby

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit
- Jupyter Notebook

## Machine Learning Workflow

1. Data Collection
2. Data Preprocessing
3. Feature Selection
4. Model Training
5. Model Evaluation
6. Model Serialization using Joblib
7. Deployment using Streamlit
